Tumblrr AI

Adversarial evaluation for AI agents that are already in production. We write the test cases most likely to cost a company money, run each one at least three times, and hand over a severity-ranked report with evidence anyone can reproduce.

  1. 01Break. Cases aimed at one weakness: prompt injection, tool misuse, data leaks, hallucinated policy.
  2. 02Reach. Trace every failure to the prompt, the tool, the retrieval or the handoff.
  3. 03Improve. Fixes ranked by severity, plus a regression pack that re-runs on every release.

How I work

Boring details, done properly

I would rather ship one small thing that works than a big thing that almost does.

Read the source, not the summary

Official docs and real behaviour beat blog posts. In BillBrake, every fact links to the provider's own page.

Small, sharp tools

Zero runtime dependencies wherever I can manage it. Fewer moving parts means fewer surprises for the people using it.

Prove it before shipping

Tests, real-world runs and a security review before anything goes public, not after the first bug report.

Write for beginners

If a sentence needs a second read, I rewrite it. That goes for docs, error messages and this page.
